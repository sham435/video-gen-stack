# NEWS-MONSTER Visual Style Guide

## Intro Structure (12s)
1. THE SIGNAL (0-2s): Black, glitch data streaks, particles
2. THE HOOK (2-4.5s): UNFILTERED text, globe wireframe, tagline
3. THE SCOPE (4.5-7.5s): BREAKING NEWS + category flicker
4. THE BRAND LOCK (7.5-12s): NM logo, sham435, LIVE dot, ticker

## Scene Types
- Hook: Breaking Banner, camera shake, impact SFX
- Fact: Giant text, keyword highlighting (gold)
- Explanation: WHY IT MATTERS heading, body text
- Retention: BREAKING ANALYSIS red, gold text
- Brand Close: Logo, CTA, anchor badge, ticker

## Captions
- 52px font, 3 words per line max
- Active word highlight (cyan glow)
- Past words dimmed
- Black pill background with rounded corners

## Motion Effects
- glitch, rgb_split, scan_lines, vignette
- camera_shake, particle_burst, light_sweep
- No static frame > 2.5 seconds
