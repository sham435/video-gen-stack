# NEWS-MONSTER Brand Identity

## Brand Name
NEWS-MONSTER

## Tagline
Unfiltered Breaking News From The Future.

## Logo
NM (gold square with black NM text)

## Colors
- Primary: #E10600 (Breaking Red)
- Secondary: #00E5FF (AI Cyan)  
- Accent: #FFD700 (Gold - logo)
- Background: #000000 / #050505
- Text: #FFFFFF

## Typography
- Headline: Anton (900 weight)
- Caption/Body: Inter (600-800 weight)
- Size hierarchy: 130px headlines, 52px captions, 42px body

- Glitch effects, scanlines, HUD overlays

- Category-specific UI themes
- 9:16 vertical format
- 30fps, 1080x1920
