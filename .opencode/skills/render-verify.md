# Skill: Footer / Visual Render Verification

Use this when asked about footer bar rendering, layout consistency, or visual asset verification.

## Key facts
- Shared layout engine: `src/video/footer/FooterLayout.mjs` (+ `blocks.mjs`).
- Text tokens shared via `src/video/footer/text-tokens.mjs` (or `text-tokens.mjs`).
- In-canvas footer drawn by `BrandingLayer.drawFooter` in the renderer.
- Standalone assets generated by `scripts/footer.mjs` (supports `--width` for responsive override,
  e.g. `node scripts/footer.mjs --width 1920`).
- Geometry is proportional to scale (9:16 default). Verify positions/height after any change.
- Tests live in `tests/footer-layout.test.mjs` (pixel-probe based).

## Steps
1. After a layout change, run the test suite (`node --test tests/footer-layout.test.mjs` or the repo
   test command) and confirm all pass.
2. Regenerate assets at required widths: `node scripts/footer.mjs --width 1080 --width 1920`.
3. Verify render output with `scripts/verify-footer-render.mjs` if present.

## Rules
1. Never claim visual correctness without running the tests.
2. Never read `.env` or files under `data/`.
